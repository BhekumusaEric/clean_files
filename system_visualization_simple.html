System Overview

The Code Clinic system facilitates peer-to-peer learning by allowing students to volunteer their time to help other students with coding problems. The system integrates with Google Calendar to manage bookings and availability.

System Diagram
Project Structure

System Architecture

The Code Clinic system consists of several components that work together:

  • Clinic Module: The main component that manages bookings and coordinates with other modules
  • Volunteer Module: Manages volunteer registration and availability
  • Calendar Sync Module: Integrates with Google Calendar to manage events
  • Config Module: Handles system configuration and settings
  • Data Store: Manages data persistence using JSON files

The system allows volunteers to register and offer time slots, which students can then book for help with coding problems.

clinic.py - Main System Module

# clinic.py - Main Code Clinic System Module

import datetime
import json
import os
from volunteer import Volunteer
from calendar_sync import get_calendar_events, create_event
from config import load_config, save_config

DATA_FILE = "data.json"

class CodeClinic:
    def __init__(self):
        """Initialize the Code Clinic system"""
        self.volunteers = {}
        self.bookings = []
        self.volunteer_slots = []
        self.load_data()
        
    def load_data(self):
        """Load data from the data file"""
        if os.path.exists(DATA_FILE):
            with open(DATA_FILE, 'r') as f:
                data = json.load(f)
                self.bookings = data.get('bookings', [])
                self.volunteer_slots = data.get('volunteer_slots', [])
                
    def save_data(self):
        """Save data to the data file"""
        data = {
            'bookings': self.bookings,
            'volunteer_slots': self.volunteer_slots
        }
        with open(DATA_FILE, 'w') as f:
            json.dump(data, f, indent=2)
            
    def register_volunteer(self, name, age, gender, student_no, email):
        """Register a new volunteer"""
        volunteer = Volunteer(name, age, gender, student_no, email)
        self.volunteers[email] = volunteer
        return volunteer

Explanation:

The clinic.py file is the main module of the Code Clinic system. It provides the core functionality for managing volunteers, bookings, and time slots.

calendar_sync.py - Google Calendar Integration

# calendar_sync.py - Google Calendar Integration Module

import datetime
import os.path
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build
from googleapiclient.errors import HttpError

# If modifying these scopes, delete the file token.json.
SCOPES = ["https://www.googleapis.com/auth/calendar.events"]

def get_credentials():
    """Get credentials for Google Calendar API"""
    creds = None
    # The file token.json stores the user's access and refresh tokens
    if os.path.exists("token.json"):
        creds = Credentials.from_authorized_user_file("token.json", SCOPES)
    # If there are no (valid) credentials available, let the user log in.
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file(
                "secrets/credentials.json", SCOPES
            )
            creds = flow.run_local_server(port=0)
        # Save the credentials for the next run
        with open("token.json", "w") as token:
            token.write(creds.to_json())
    return creds

Explanation:

The calendar_sync.py file handles integration with Google Calendar API, allowing the system to create, update, and delete events in users' calendars.
