# Code Clinic System

A comprehensive system for managing peer-to-peer learning sessions. This repository contains web-based visualizations and demos of the Code Clinic system.

## Overview

The Code Clinic system facilitates peer-to-peer learning by allowing students to volunteer their time to help other students with coding problems. The system integrates with Google Calendar to manage bookings and availability.

## Getting Started

To use the actual Code Clinic system (not just the demos), follow these steps:

1. Clone the repository: `git clone https://github.com/wethinkcode/fun-ex-code-clinics.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Set up Google Calendar API: Follow the instructions in the README to set up your Google Calendar API credentials
4. Run the commands: Use the CLI commands shown in the demos to interact with the system

For more information, refer to the project documentation or run `python clinic.py --help` to see all available commands and options.
