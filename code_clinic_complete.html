Code Clinic System

The Code Clinic system facilitates peer-to-peer learning by allowing students to volunteer their time to help other students with coding problems. The system integrates with Google Calendar to manage bookings and availability.

clinic.py - Main System Module

# clinic.py - Main Code Clinic System Module

import datetime
import json
import os
from volunteer import Volunteer
from calendar_sync import get_calendar_events, create_event
from config import load_config, save_config

DATA_FILE = "data.json"

class CodeClinic:
    def __init__(self):
        """Initialize the Code Clinic system"""
        self.volunteers = {}
        self.bookings = []
        self.volunteer_slots = []
        self.load_data()
        
    def load_data(self):
        """Load data from the data file"""
        if os.path.exists(DATA_FILE):
            with open(DATA_FILE, 'r') as f:
                data = json.load(f)
                self.bookings = data.get('bookings', [])
                self.volunteer_slots = data.get('volunteer_slots', [])
                
    def save_data(self):
        """Save data to the data file"""
        data = {
            'bookings': self.bookings,
            'volunteer_slots': self.volunteer_slots
        }
        with open(DATA_FILE, 'w') as f:
            json.dump(data, f, indent=2)
            
    def register_volunteer(self, name, age, gender, student_no, email):
        """Register a new volunteer"""
        volunteer = Volunteer(name, age, gender, student_no, email)
        self.volunteers[email] = volunteer
        return volunteer

Explanation:

The clinic.py file is the main module of the Code Clinic system. It provides the core functionality for managing volunteers, bookings, and time slots.

calendar_sync.py - Google Calendar Integration

# calendar_sync.py - Google Calendar Integration Module

import datetime
import os.path
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build
from googleapiclient.errors import HttpError

# If modifying these scopes, delete the file token.json.
SCOPES = ["https://www.googleapis.com/auth/calendar.events"]

def get_credentials():
    """Get credentials for Google Calendar API"""
    creds = None
    # The file token.json stores the user's access and refresh tokens
    if os.path.exists("token.json"):
        creds = Credentials.from_authorized_user_file("token.json", SCOPES)
    # If there are no (valid) credentials available, let the user log in.
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file(
                "secrets/credentials.json", SCOPES
            )
            creds = flow.run_local_server(port=0)
        # Save the credentials for the next run
        with open("token.json", "w") as token:
            token.write(creds.to_json())
    return creds

Explanation:

The calendar_sync.py file handles integration with Google Calendar API, allowing the system to create, update, and delete events in users' calendars.

config.py - Configuration Management

# config.py - Configuration Management Module

import os
import json

CONFIG_FILE = os.path.expanduser("~/.code_clinic_config")

def load_config():
    """Load configuration from the config file"""
    if os.path.exists(CONFIG_FILE):
        with open(CONFIG_FILE, 'r') as f:
            return json.load(f)
    return {}

def save_config(config_data):
    """Save configuration to the config file"""
    with open(CONFIG_FILE, 'w') as f:
        json.dump(config_data, f, indent=2)

Explanation:

The config.py file provides functionality for managing system configuration settings, storing them in a JSON file in the user's home directory.

cli.py - Command Line Interface

# cli.py - Command Line Interface Module

import argparse
import sys
from clinic import CodeClinic
from utils import validate_email, validate_date, validate_time

def parse_args():
    """Parse command line arguments"""
    parser = argparse.ArgumentParser(description='Code Clinic CLI')
    subparsers = parser.add_subparsers(dest='command', help='Command to run')
    
    # Register volunteer command
    register_parser = subparsers.add_parser('register', help='Register as a volunteer')
    register_parser.add_argument('--name', required=True, help='Volunteer name')
    register_parser.add_argument('--age', required=True, type=int, help='Volunteer age')
    register_parser.add_argument('--gender', required=True, help='Volunteer gender')
    register_parser.add_argument('--student-no', required=True, help='Student number')
    register_parser.add_argument('--email', required=True, help='Email address')
    
    # Add slot command
    slot_parser = subparsers.add_parser('add-slot', help='Add a volunteer time slot')
    slot_parser.add_argument('--email', required=True, help='Volunteer email')
    slot_parser.add_argument('--date', required=True, help='Date (YYYY-MM-DD)')
    slot_parser.add_argument('--time', required=True, help='Time (HH:MM)')
    slot_parser.add_argument('--duration', type=int, default=30, help='Duration in minutes')

Explanation:

The cli.py file provides a command-line interface for interacting with the Code Clinic system, allowing users to register, add slots, book sessions, and view information.

Volunteer CLI Commands

As a volunteer, you can register yourself, add available time slots, and manage your bookings using the following commands.

1. Registering as a Volunteer

user@wethinkcode:~$ python clinic.py register --name "John Doe" --age 25 --gender "Male" --student-no "WTC_12345" --email "john.doe@example.com" Volunteer registered: John Doe (john.doe@example.com) - Student #WTC_12345

2. Adding Available Time Slots

user@wethinkcode:~$ python clinic.py add-slot --email "john.doe@example.com" --date "2023-06-01" --time "14:00" --duration 30 Slot added: 2023-06-01 14:00 (30 minutes)

3. Viewing Your Available Slots

user@wethinkcode:~$ python clinic.py list-slots --volunteer "john.doe@example.com" Available slots for John Doe: 1: 2023-06-01 14:00 - 14:30 (Available) 2: 2023-06-03 10:00 - 10:45 (Available)

Getting Started

To use the Code Clinic system, follow these steps:

  1. Clone the repository: git clone https://github.com/wethinkcode/fun-ex-code-clinics.git
  2. Install dependencies: pip install -r requirements.txt
  3. Set up Google Calendar API: Follow the instructions in the README to set up your Google Calendar API credentials
  4. Run the commands: Use the commands shown in the demo above to interact with the system

For more information, refer to the project documentation or run python clinic.py --help to see all available commands and options.
