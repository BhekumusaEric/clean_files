Volunteer CLI Commands

As a volunteer, you can register yourself, add available time slots, and manage your bookings using the following commands.

1. Registering as a Volunteer

user@wethinkcode:~$ python clinic.py register --name "John Doe" --age 25 --gender "Male" --student-no "WTC_12345" --email "john.doe@example.com" Volunteer registered: John Doe (john.doe@example.com) - Student #WTC_12345

2. Adding Available Time Slots

user@wethinkcode:~$ python clinic.py add-slot --email "john.doe@example.com" --date "2023-06-01" --time "14:00" --duration 30 Slot added: 2023-06-01 14:00 (30 minutes) user@wethinkcode:~$ python clinic.py add-slot --email "john.doe@example.com" --date "2023-06-03" --time "10:00" --duration 45 Slot added: 2023-06-03 10:00 (45 minutes)

3. Viewing Your Available Slots

user@wethinkcode:~$ python clinic.py list-slots --volunteer "john.doe@example.com" Available slots for John Doe: 1: 2023-06-01 14:00 - 14:30 (Available) 2: 2023-06-03 10:00 - 10:45 (Available)

4. Viewing Your Bookings

user@wethinkcode:~$ python clinic.py list-bookings --email "john.doe@example.com" --type volunteer Bookings for John Doe: No bookings found # After a student books a slot: user@wethinkcode:~$ python clinic.py list-bookings --email "john.doe@example.com" --type volunteer Bookings for John Doe: 1: 2023-06-01 14:00 - 14:30 Student: alice@example.com Description: Help with Python classes and inheritance

Student CLI Commands

As a student, you can view available slots, book sessions, and manage your bookings using the following commands.

1. Viewing Available Slots

user@wethinkcode:~$ python clinic.py list-slots Available slots: 0: 2023-06-01 14:00 - 14:30 (John Doe) 1: 2023-06-03 10:00 - 10:45 (John Doe) 2: 2023-06-07 11:00 - 12:00 (Jane Smith)

2. Booking a Slot

user@wethinkcode:~$ python clinic.py book --email "alice@example.com" --slot-index 0 --description "Help with Python classes and inheritance" Slot booked successfully Booking details: Date: 2023-06-01 Time: 14:00 - 14:30 Volunteer: John Doe (john.doe@example.com) The booking has been added to your Google Calendar

3. Viewing Your Bookings

user@wethinkcode:~$ python clinic.py list-bookings --email "alice@example.com" --type student Bookings for alice@example.com: 0: 2023-06-01 14:00 - 14:30 Volunteer: John Doe (john.doe@example.com) Description: Help with Python classes and inheritance

4. Cancelling a Booking

user@wethinkcode:~$ python clinic.py cancel-booking --email "alice@example.com" --booking-index 0 Booking cancelled successfully The slot is now available for booking again The event has been removed from your Google Calendar

Admin CLI Commands

As an administrator, you can manage the entire system, view all bookings, and perform maintenance tasks using the following commands.

1. Viewing All Volunteers

user@wethinkcode:~$ python clinic.py list-volunteers Registered volunteers: 1. John Doe (john.doe@example.com) - Student #WTC_12345 2. Jane Smith (jane.smith@example.com) - Student #WTC_67890

2. Viewing All Slots

user@wethinkcode:~$ python clinic.py list-all-slots All slots: 1. 2023-06-01 14:00 - 14:30 (John Doe) - Booked by alice@example.com 2. 2023-06-03 10:00 - 10:45 (John Doe) - Available 3. 2023-06-07 11:00 - 12:00 (Jane Smith) - Available

3. Viewing All Bookings

user@wethinkcode:~$ python clinic.py list-all-bookings All bookings: 1. 2023-06-01 14:00 - 14:30 Student: alice@example.com Volunteer: John Doe (john.doe@example.com) Description: Help with Python classes and inheritance

4. Syncing with Google Calendar

user@wethinkcode:~$ python calendar-sync.py Syncing with Google Calendar... Authenticating with Google... Authentication successful! Syncing slots and bookings... 3 slots synced 1 booking synced Sync completed successfully!

5. Backing Up Data

user@wethinkcode:~$ python clinic.py backup Creating backup of all data... Backing up volunteers... Backing up slots... Backing up bookings... Backup created successfully: backup_2023-06-01.zip

Getting Started

To use the Code Clinic system, follow these steps:

  1. Clone the repository: git clone https://github.com/wethinkcode/fun-ex-code-clinics.git
  2. Install dependencies: pip install -r requirements.txt
  3. Set up Google Calendar API: Follow the instructions in the README to set up your Google Calendar API credentials
  4. Run the commands: Use the commands shown in the demo above to interact with the system

For more information, refer to the project documentation or run python clinic.py --help to see all available commands and options.
