# Code Clinic Project - Kickoff Meeting Checklist

## Pre-Meeting Setup
- [ ] Ensure all team members have access to Miro board
- [ ] Verify everyone has GitLab project access
- [ ] Schedule daily stand-up meeting time
- [ ] Prepare project requirements overview

## Meeting Agenda (60 minutes)

### 1. Introductions & Role Clarification (10 mins)
- [ ] Team member introductions
- [ ] Identify individual exercise completion status
- [ ] Discuss availability and commitment levels
- [ ] Assign initial roles (Scrum Master, Product Owner, etc.)

### 2. Miro Board Setup & Training (15 mins)
- [ ] Walk through Miro board structure
- [ ] Practice adding cards, moving items
- [ ] Set up board sections:
  - [ ] Product Backlog
  - [ ] Iteration 1 Sprint Board
  - [ ] Retrospective sections
  - [ ] Team information

### 3. Project Requirements Review (20 mins)
- [ ] Review Code Clinic system overview
- [ ] Understand core features:
  - [ ] Student registration and volunteer registration
  - [ ] Time slot management
  - [ ] Booking system
  - [ ] Google Calendar integration
  - [ ] CLI interface
- [ ] Clarify acceptance criteria
- [ ] Identify technical risks

### 4. Team Coordination Strategy (10 mins)
- [ ] Daily stand-up time: ________________
- [ ] Communication channels (Slack, WhatsApp, etc.)
- [ ] Support plan for team members completing individual exercises
- [ ] Pair programming schedule

### 5. Initial Planning Discussion (5 mins)
- [ ] Identify major work streams
- [ ] Discuss iteration length and goals
- [ ] Plan next planning session

## Action Items
- [ ] Set up GitLab issues board
- [ ] Create initial user stories
- [ ] Schedule planning session for Step 2
- [ ] Individual exercise catch-up plan
